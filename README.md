# Dota Helper — MVP (Этапы 1–11 плана)

Стек: React + TypeScript + Vite + Tailwind CSS + React Router. Данные — JSON (Этап 0: допустимо для старта, легко заменить на БД позже — весь доступ к данным идёт только через `src/data/*.json`, поэтому замена на API/Postgres не затронет компоненты).

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173

## Что уже реализовано

- **Архитектура (Этап 1):** данные (`src/data`), типы (`src/types`), компоненты (`src/components`), страницы (`src/pages`) разделены. Компоненты не содержат данных героев/предметов "зашитыми" внутри.
- **Роутинг (Этап 2):** `/`, `/heroes`, `/heroes/:id`, `/items`, `/items/:id`, `/counterpick`, `/lanes`.
- **Тёмный дизайн (Этап 3):** карточки, тёмная палитра, hover-переходы, адаптивное меню.
- **База героев (Этап 4)** и **каталог героев с поиском/фильтрами по позиции и атрибуту** (Этап 5).
- **Страница героя** с характеристиками, способностями и блоком Power Treads (Этапы 6, 9).
- **База предметов (Этап 7)** и **каталог предметов с поиском/категориями** (Этап 8).
- **Контрпик (Этапы 10–11):** выбор своего героя и героя противника, вывод контргероев/контрпредметов/опасностей/советов. Данные заполнены демо-примером для Axe — остальных героев легко добавить в `src/data/counters.json`.
- Адаптивная вёрстка (мобильное меню-гамбургер) — базовая версия Этапа 15, будет дорабатываться.

## Что дальше по плану

- Этап 12–13: полноценная логика "Помощь с линией" (сейчас заглушка на `/lanes`) и структурированные рекомендации.
- Этап 14: полноценный глобальный поиск (сейчас поле есть в шапке, но не подключено).
- Этап 16–20: анимации, реальные данные Dota 2 (API), админка, авторизация, доп. функции.

## Наполнение данными

Сейчас заполнено 3 героя (Juggernaut, Axe, Lion) и 3 предмета — этого достаточно, чтобы проверить всю механику (карточки, фильтры, страницы, контрпик). Остальных героев/предметы Dota 2 добавляйте по той же структуре в `src/data/heroes.json` и `src/data/items.json`.

## Изображения

Поле `image` в JSON сейчас указывает на несуществующие пути (`/heroes/*.png`, `/items/*.png`) — карточки временно показывают текстовую заглушку вместо картинки. Когда будут реальные изображения героев/предметов, положите их в `public/heroes/` и `public/items/`.
